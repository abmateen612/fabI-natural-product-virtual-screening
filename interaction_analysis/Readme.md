# Interaction analysis

2D protein-ligand interaction diagrams made in Discovery Studio Visualizer 2025,
one file per compound, named after the compound.

Each diagram shows the interactions between a docked ligand and the FabI binding
site (PDB: 6AHE, NAD retained): hydrogen bonds, hydrophobic contacts and other
contacts, with distances. They were used to choose the 4 compounds that went to
molecular dynamics.
