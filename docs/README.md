# Documentation

This directory contains detailed methodological documentation for the major stages of the FabI virtual-screening workflow.

The documents explain the computational procedures, parameters, filtering criteria, and decision points used throughout the project.

## Documents

| Document | Description |
|---|---|
| `protein_preparation.md` | FabI target selection, structure preparation, and docking-grid definition |
| `rdkit_filtering.md` | Natural-product library processing and RDKit-based chemical filtering |
| `docking.md` | AutoDock Vina docking procedure and docking-score prioritization |
| `post_docking_pipeline.md` | PCA, clustering, ligand-efficiency analysis, and post-docking prioritization |

These documents complement the computational notebooks and result files provided elsewhere in the repository.
