# Computational Notebooks

This directory contains the Jupyter Notebooks used for cheminformatics processing and post-docking analysis.

## Files

| File | Description |
|---|---|
| `rdkit_filtering.ipynb` | RDKit-based processing and chemical filtering of the natural-product library |
| `post_docking_analysis.ipynb` | PCA, chemical-space analysis, clustering, ligand-efficiency analysis, and protein-ligand complex preparation |

## Workflow

The notebooks correspond to two major computational stages of the project:

1. **RDKit Filtering**
   - Structure processing
   - Lipinski filtering
   - PAINS filtering
   - Rotatable-bond filtering

2. **Post-Docking Analysis**
   - Molecular fingerprint generation
   - PCA
   - Cluster analysis
   - Candidate selection
   - Ligand-efficiency analysis
   - Protein-ligand complex preparation

The notebooks contain the computational implementation and analysis used to generate the corresponding project results.
