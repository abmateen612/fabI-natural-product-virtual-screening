# Figures

This directory contains the key visual outputs generated during the virtual-screening and post-docking analysis workflow.

## Contents

### PCA

Principal Component Analysis plots showing the chemical-space distribution of the docked compounds.

### Clustering

Plots generated during cluster-number evaluation and chemical-space clustering, including elbow and silhouette analysis.

### Interaction Analysis

Protein-ligand interaction diagrams generated using BIOVIA Discovery Studio for the 9 final computationally prioritized candidates.

## Purpose

The figures provide visual evidence supporting the computational prioritization process and complement the numerical results and analysis notebooks.
